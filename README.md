# Tu Tiên 2D — Tự động

Auto cho game Tu Tiên 2D (tutien2d.com): treo quái, săn boss theo thông báo Thiên Đạo, đi theo tuyến mẫu, tránh map PK.

## Cài đặt (mỗi máy làm một lần)

1. Cài tiện ích **Tampermonkey** cho Chrome.
2. Bấm vào link sau, Tampermonkey sẽ mở trang cài đặt → bấm **Install / Cài đặt**:
   https://raw.githubusercontent.com/doanquang27/tutien2d-auto/main/tutien2d-auto.user.js
3. Nếu đang dùng bản tiện ích giải nén (`tutien2d-auto-extension`), gỡ nó trong `chrome://extensions` để không chạy 2 bản.
4. Tải lại trang game, nhập **mã kích hoạt** ở khung hiện ra (mỗi máy nhập một lần). Bảng auto hiện số phiên bản ở góc trên.

## Cập nhật

Tampermonkey tự kiểm tra bản mới theo chu kỳ (chỉnh trong Tampermonkey → Cài đặt → "Kiểm tra cập nhật").
Muốn lấy ngay: mở Tampermonkey → Bảng điều khiển → bấm biểu tượng cập nhật, hoặc bấm lại link cài đặt ở trên.
